# 센서별 값 해석·보정 안내 — v0.2.0

## 아날로그 원시값을 읽는 방법

micro:bit의 아날로그 원시값은 **0~1023**이다. 1024개의 단계가 있다는 뜻이며 최대값이 1024인 것은 아니다. 단순 아날로그 센서는 `센서 → 아날로그 입력`의 센서별 이름 블록으로 읽는다. 새 디지털 입력 블록은 **0 또는 1**이다. 이 값만으로 단선 여부를 판별할 수는 없다. [MakeCode 공식 ADC 안내](https://makecode.microbit.org/reference/pins/analog-read-pin).

ADC 입력 전압의 근사값은 `Vadc = raw × Vref / 1023`이다. 일반 예제에서는 Vref를 3.3V로 두지만 전원·분압·ADC 오차가 포함된다. 외부 분압비가 k라면 센서 출력 전압은 `Vsensor = Vadc × k`이다. 센서 기판 이름이 “5V”나 “25V”여도 micro:bit 입력 허용 전압이 커지지는 않는다.

실제 물리량과 직선 관계가 확인된 센서는 두 기준점 `(r1,q1)`, `(r2,q2)`로 `q = q1 + (raw-r1) × (q2-q1)/(r2-r1)`을 사용할 수 있다. 두 원시값은 달라야 한다. **CdS·FSR·가스처럼 비선형인 센서에 이 식을 전체 범위의 정답으로 적용하지 않는다.**

새 보정값은 핀별 RAM에 보관되며 프로그램 재시작 시 사라진다. 잘못된 재보정은 이전 계수를 무효화한다. 보정할 때 값을 충분히 안정시키고, 보정 뒤에는 보정에 쓰지 않은 다른 기준점으로 오차를 확인한다.

## 전류 센서(WCS2801)

- **블록:** `zeroCurrent`, `calibrateCurrent`, `currentAmps`.
- **준비물:** 기준 전류계/멀티미터, 안정된 저전압 DC 전원, 정격에 맞는 부하. 이 블록은 1A 모듈용이다.
- 전류가 흐르지 않게 한 뒤 `전류 영점`을 실행한다. 기준계로 확인한 전류를 흘리고 `기준 전류 … A 보정`을 실행한 뒤 A 리포터를 읽는다. 기준 전류의 부호도 실제 방향에 맞춘다.
- `A = (raw-zero)/(referenceRaw-zero) × referenceA`. 보정 기준은 절댓값 0.05~1A, 출력은 ±1A 범위다. 보정 전·포화·범위 초과는 **-9999**다. 음의 정상 전류와 실패값을 구분한다.
- 공급 전압에 따라 감도가 달라진다. ACS712의 감도 상수를 쓰지 않는다. 새 코드와 안정 표본 처리는 Science Lab에서 가져왔다. [Winson WCS2801 자료](https://www.winson.com.tw/uploads/images/CWCS2801.pdf).

## 전압 센서(분압 모듈)

- **블록:** `voltageRaw`, `calibrateVoltage`, `voltageCalibrated`.
- **준비물:** 멀티미터, 안정된 저전압 DC 기준 전원, 모듈의 실제 분압비 정보.
- 기준 전압을 **분압 모듈을 통해** 연결하고 멀티미터로 확인한 값을 `기준 … V 보정`에 넣는다. 같은 핀의 `보정 전압` 리포터를 읽는다.
- `V = raw × referenceV/referenceRaw`. 기준 입력은 양수이며 ADC가 포화되지 않아야 한다. **0V는 정상값**, 미보정·포화·실패는 **-1**이다.
- 5:1 분압이라면 3.3V 입력 기준의 이상적 상한은 16.5V다. 실제 여유를 두고 사용하며 “25V” 모듈명만으로 25V를 넣지 않는다. 외장 ADS1115는 사용하지 않는다.
- 기존 `voltageRead`는 고정 5:1 분압·3.3V 가정이다. 기준 보정 리포터와 구분한다.

## 탁도 센서(AZDM01)

- **블록:** `turbidityRaw`, `calibrateTurbidity`, `turbidityTransmission`.
- **준비물:** 맑은 물, 같은 투명 용기, 외부 빛을 가릴 차광 덮개, 비교할 시료.
- 기포와 오염을 없애고 맑은 물에서 보정한다. 센서 깊이·방향·주변 조명을 고정한 뒤 시료를 바꿔 읽는다.
- `상대 투과율 = raw/clearRaw × 100`. 맑은 물을 100으로 둔 **전기 신호의 상대 비율**이다. 광학 투과율이나 표준 NTU로 인증한 값이 아니다. 0은 정상값이고 미보정·포화·120 초과는 **-1**이다.
- 기존 `turbidityRead`의 0~3000 선택지도 **상대 탁도**로 이름을 바로잡았다. 기존 코드의 enum 이름 `NTU`는 프로젝트 호환용으로만 남긴다. 실제 NTU 환산에는 표준 탁도액 여러 점과 검증된 보정 곡선이 필요하다.
- 직접 ADC를 사용하며 외장 ADS1115는 필요 없다. [AZDM01 제조사 자료 사본](https://xonstorage.blob.core.windows.net/pdf/aosong_azdm01_apr22_xonlink.pdf).

## 자외선 센서(GUVA-S12SD)

- **블록:** `uvRaw`, `uvInit`, `uvCalibrate`, `uvSetReference`, `uvRead`.
- **준비물:** 차광 덮개, 측정하려는 단위에 맞는 UV 기준계, 안정된 광원.
- 시작 핀을 설정하고 차광한 상태에서 `실내/영점 보정`의 기준 전압을 0으로 두어 현재 값을 잡는다. 이후 기준계와 같은 조건에서 `기준값 보정`을 실행한다.
- UVI와 mW/cm²는 서로 다른 단위이며 **각각 따로 보정**한다. 한 단위를 보정했다고 다른 단위까지 유효해지지 않는다. 미보정 물리량은 **-1**, 입력 전압(mV)은 보정 없이 비교할 수 있다.
- 이 보정은 같은 광원·배치에서의 기준 비교다. GUVA의 파장 응답과 기준계의 응답 차이 때문에 모든 광원에서 표준 UV 지수가 보장되는 것은 아니다.

## 아날로그 미세먼지(GP2Y1014AU0F)

- **블록:** `analogDustRaw(signal, lamp)`.
- **준비물:** 실제 센서 회로에 맞는 LED 구동 회로, 신호 전압 분압, 비교용 먼지 계기와 일정한 공기 흐름.
- VO는 보호된 아날로그 핀, LED 제어는 별도 디지털 핀에 연결한다. 센서 전원과 LED 구동 조건을 기판 회로에 맞춘다. 블록은 10ms 이상 간격의 LED 펄스와 동기 ADC 표본 8회의 평균 원시값을 낸다.
- 정상 **0~1023**, ADC 사용 충돌·표본 타이밍 실패는 **-1**이다. 아직 PM2.5, PM10, µg/m³로 자동 환산하지 않는다. 기준계·먼지 입자 조건으로 영점과 감도 곡선을 별도로 검증해야 한다.
- P0를 사용하면 내장 오디오 핀 기능을 끄고, LED 행렬과 겹치는 아날로그 핀에서는 행렬을 끈다. V2 네이티브 표본 코드이며 실제 배선·타이밍 시험은 남아 있다. [Sharp 제품 자료](https://global.sharp/products/device/lineup/selection/opto/dust/index.html).

## 단순 아날로그 센서별 해석

| 센서 / 전용 블록 | 준비물과 기준 | 값 해석·변환 |
|---|---|---|
| 빛(CdS) / `light` | 조도계, 차광 상자, 여러 밝기의 광원 | 밝기에 따라 증가·감소하는 방향부터 확인. 저항과 밝기는 비선형이므로 여러 점 곡선이 있어야 lux로 환산 가능. |
| 소리 / `sound` | 일정한 소리, 고정 거리, 소음계 | 원시 표본 하나는 음량이 아님. 같은 시간 창의 최대-최소 또는 RMS로 비교. dB는 기준 소음계·모듈 응답 보정 필요. |
| 토양 수분 / `soilMoisture` | 같은 흙의 건조·젖은 표본 | 두 끝점을 0~100%에 매핑하면 상대 젖음도. 절대 토양 함수율과 구분. |
| 물 감지 / `water` | 마른 표면, 일정 높이의 물 | 원시 신호·임계값으로 젖음 판단. 물 높이 cm는 일정 용기·전도도에서 여러 점 실측 필요. |
| 빗물 / `rain` | 마른 판, 일정량의 물방울 | 젖은 정도 비교. 강수량 mm로 직접 변환 불가. |
| 진동 / `vibration` | 고정 장착, 진동 없는 기준 | 같은 시간 창의 편차·최대-최소 비교. 주파수/가속도 단위는 기준 진동계와 표본 주기 검증 필요. |
| 자기(SS49E) / `magnet` | 무자장 기준, 기준 자속계 | 영점을 뺀 값으로 방향·변화 비교. mT는 공급전압·감도·온도 보정 후 해석. |
| 힘/압력(FSR) / `force` | 분동, 고정 접촉 면적·받침 | 여러 하중의 보정 곡선 사용. ADC를 바로 kg/N/Pa로 표시하지 않음. |
| 회전 가변저항 / `rotation` | 양 끝의 원시값, 각도 눈금 | 두 끝점 선형 매핑으로 상대 % 또는 기구 각도 계산. |
| 슬라이더 / `slider` | 양 끝 원시값, 자 | 두 끝점 매핑으로 상대 % 또는 이동거리 계산. |
| 무한회전 / `infiniteRotation` | 천천히 한 바퀴 돌려 파형 기록 | 원시 파형만 제공. 경계 통과·회전수·방향 누적은 모듈 구조에 맞게 별도 처리. |
| 4패드 터치 / `analogTouch` | 패드별 누르지 않음/누름 원시값 | 실물의 각 ADC 구간으로 패드 번호 판별. 범용 공통 임계값이나 동시 터치 해석을 가정하지 않음. |
| 라인 감지 / `line` | 같은 높이에서 검정·흰색 표본 | 두 분포 사이 임계값 설정. 센서 AO/DO 핀 구분. |
| IR 물체 감지 / `object` | 같은 색·각도·거리의 물체 | 반사량 비교와 감지 임계값. 표면이 바뀌면 원시값과 cm 관계도 바뀜. |
| 가스 MQ-2/3/4/5/6/7/8/9/135 / `mqReadRaw` 또는 기본 아날로그 입력 | 데이터시트의 히터 조건, 기준 가스·농도 | 사용자 요청대로 원시값 변화 관찰에 사용. ppm에는 각 가스별 R0·Rs/R0 곡선·부하저항·환경 보정이 필요. |

## 디지털 입력·출력 장치

버튼, 잠금 스위치, 터치, PIR, 기울기, 디지털 진동, 수위, 포토인터럽터, 불꽃 센서는 `디지털 입력` 그룹의 센서별 블록을 사용한다. 정상 0/1의 의미는 실물 Active HIGH/LOW와 일치하는지 직접 누르거나 가려서 확인한다. 센서가 없는 핀도 0/1이 될 수 있으므로 연결 확인과는 다르다. 포토인터럽터는 바퀴 슬롯 수와 펄스 주기를 함께 알아야 RPM을 계산할 수 있다.

LED·릴레이·전자석·진동모터·레이저 모듈은 기본 디지털 출력, RGB LED는 채널별 PWM을 사용한다. 모터·펌프·서보는 정격 전원과 드라이버가 필요하다. 서보는 제조사 펄스 범위와 기구 끝점을 확인하고, 스테퍼는 한 바퀴의 스텝 수·마이크로스텝·기어비를 설정한다. 표시 장치는 I2C 주소, 핀, 화면 크기/픽셀 수를 맞춘다. 전체 장치별 대응 명령은 [입출력 장치 지원 목록](device-support.md)에 있다.

## 오류값을 전송하는 프로그램

측정 실패를 0으로 바꿔 바우어버드로 보내면 정상 0과 구분할 수 없다. 센서별 유효 상태·오류값을 먼저 확인하고, 실패값은 그래프 표본에서 제외하거나 별도 상태 채널로 전송한다. 이 확장의 모든 기존 리포터가 하나의 오류값 규칙을 공유하는 것은 아니다. **-1/-9999 또는 준비 상태의 의미를 사용한 블록별로 확인**한다.
