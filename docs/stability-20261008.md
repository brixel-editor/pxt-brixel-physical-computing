# v0.2.0 안정화 결과

## 검토 기준

사용자가 제공한 장치 Excel 4개를 원본 수정 없이 읽고, 장치명 729건을 블록 선언·구현과 대조했다. 모델명·통신 방식이 불분명한 행은 유사한 센서에 임의로 합치지 않았다. 사용자 확인 사항인 **MAX30102, MH-Z19D UART, GV–Echo–Trig 4핀 초음파, 외장 ADS1115 없음**을 반영했다.

[장치별 지원표](device-support.md)에는 102개 검토 묶음과 원본 셀이 있다. 보드·부속품 3묶음을 제외한 99묶음은 전용 블록 69, 기본 핀 블록 17, 일부 지원 4, 미지원 3, 모델 확인 필요 6이다. “전용 블록”은 구현 존재를 뜻하며 실물 통과 판정은 아니다.

## 검증 결과

- **기존 블록 435개**의 함수명·매개변수·기본 인자와 기존 enum 멤버·값 보존 검사 통과.
- 현재 **476개 함수 블록, 389개 드롭다운 항목, 10개 카테고리, 81개 그룹**. 함수 블록 수에는 숨김/폐기 예정 보조 블록도 포함한다.
- PXT 자체 블록 문자열 파서로 476개 정의와 35개 언어 자료의 매개변수 연결 검사 통과. 새 블록은 한국어/영어, 다른 언어는 영어 폴백.
- 실제 TypeScript를 모의 I/O로 실행한 **회귀 시험 28건 통과**. 정상값뿐 아니라 타임아웃·잘못된 CRC·오래된 값·분할 프레임·잘못된 보정 기준을 시험했다.
- **micro:bit V2 네이티브 빌드 3종 통과**: TFT+심박, 신규 보정+네이티브 먼지+PCA9685+WebSocket, 10개 카테고리 통합. PXT micro:bit 9.1.1 / core 13.0.1 사용.
- 공개 패키지의 각 컴파일 입력 파일은 64KB 미만이며, 원본 개발 폴더의 파일 해시는 유지됐다.
- 검사 시각·프로필·소스 해시는 [검증 기록 JSON](verification-v0.2.0.json)에 있다.

회귀 시험 원본은 [tests/runtime-tests.cjs](../tests/runtime-tests.cjs)다. Node.js 환경에서 별도 검사용 복사본에 `npm install --no-save pxt-core@13.0.1` 후 `node tests/runtime-tests.cjs`로 실행한다. 이 시험은 ADC·UART·I2C 응답을 모의하며 네이티브 타이밍·전기 신호·센서 정확도를 대체하지 않는다.

## 남은 범위

**실물 전체 검증은 하지 않았다.** 모듈별 전원·전압·풀업·응답·타이밍과 측정 정확도는 실제 보드에서 확인해야 한다. SD/TF 파일 API와 RF433 송수신은 미지원이다. L293DD 4핀 보드, TC118 팬, HX711 I2C 어댑터 및 모델 미기재 장치는 확인이 필요하다.

MH-Z19D의 온도 진단·범위·ABC 부가 명령은 공개 D 문서만으로 모두 확인되지 않는다. MLX90614 PEC 검사, 센서별 장기 안정성, 실제 ESP AT 펌웨어별 호환성, 다른 I/O와 동시에 사용하는 1-Wire/IR/먼지 표본 타이밍 등은 실물 검증 항목이다. WiFi/센서/USB는 한 UART를 번갈아 쓰므로 연속 수신을 동시에 보장하지 않는다. 기존 모든 리포터의 실패 규칙이 통일된 것은 아니다.

실물 확인 순서는 ① 장치 하나와 짧은 프로그램으로 연결 확인 → ② 센서 분리/오류 상태 확인 → ③ 기준계와 여러 점 비교 → ④ 다른 장치와 함께 사용하며 간섭 확인이다. 센서별 준비물은 [보정 안내](sensor-calibration.md)에 정리했다.

## 기존 프로젝트 업데이트

`_Fo84JDihLTPm` 공유 프로젝트는 v0.1.0을 포함한 기존 스냅샷이다. **코드 수정 → JavaScript → 탐색기의 확장 업데이트**로 v0.2.0을 선택하거나, 확장 검색에 `https://github.com/brixel-editor/pxt-brixel-physical-computing#v0.2.0`을 사용한다. 함수 API는 보존했지만, 오류값을 0/이전값으로 가정한 프로그램은 위의 실패값 변경에 맞춰 조건을 추가해야 한다.
